## 📖 Descripción general

**Detalles Belis** es una landing page desarrollada para fortalecer la presencia digital de un emprendimiento especializado en regalos personalizados.

El proyecto nace de la necesidad de ofrecer un espacio digital donde los clientes puedan descubrir el catálogo de productos, conocer la propuesta de valor del negocio y realizar consultas de manera sencilla.

La solución combina **HTML5, CSS3, JavaScript y Tailwind CSS**, integrando diseño responsive, interactividad, accesibilidad web y optimización SEO en una plataforma ligera que no requiere dependencias de instalación para su ejecución local.

El resultado es una experiencia visual e intuitiva, diseñada para facilitar el descubrimiento de productos y dirigir a los clientes hacia el contacto directo mediante WhatsApp.

---

## ✨ Filosofía de diseño (UI/UX)

La interfaz se construyó siguiendo principios de diseño centrados en la experiencia del usuario, buscando transmitir cercanía, elegancia y una identidad visual coherente con la naturaleza del negocio.

### 🎨 Identidad visual y temas

El proyecto incorpora dos esquemas visuales que permiten adaptar la experiencia a las preferencias del usuario:

- **Tema claro (`#FFF9FA`):** una apariencia luminosa y delicada que favorece la lectura y presentación de los productos.
- **Tema oscuro (`#171416`):** una alternativa visual de tonos oscuros que conserva la identidad del sitio y facilita la navegación en diferentes condiciones de iluminación.

### 🔤 Tipografía

Se utiliza una combinación tipográfica que equilibra elegancia, personalidad y legibilidad:

- **Playfair Display:** aporta un carácter editorial y sofisticado a los títulos.
- **Poppins:** proporciona claridad y modernidad en los textos y elementos de interfaz.
- **Dancing Script:** incorpora detalles expresivos y decorativos en elementos seleccionados.

### 🧩 Componentes e interacciones

La interfaz integra tarjetas de productos, ventanas modales, carruseles y controles interactivos, manteniendo una jerarquía visual consistente.

### 📐 Diseño responsive

Se aplica un enfoque *mobile-first*, con ajustes específicos de distribución, tipografía y navegación según las dimensiones de pantalla.

## 🚀 Características principales

### 1. Diseño responsive y adaptación visual

- **Enfoque mobile-first:** adaptación de la interfaz para smartphones, tablets, laptops y monitores de escritorio.
- **Distribución flexible:** reorganización de elementos, tipografías y grillas según el espacio disponible.
- **Consistencia visual:** contenedores, márgenes y espaciados compartidos para mantener una presentación ordenada en diferentes resoluciones.

### 2. Experiencia visual e interactividad

- **Catálogo visual:** tarjetas de productos con imágenes verticales y modal interactivo para ampliar su visualización.
- **Carrusel de testimonios:** presentación dinámica con controles de navegación y comportamiento adaptable.
- **Preloader personalizado:** pantalla de carga alineada con la identidad visual del negocio.
- **Microinteracciones:** contadores animados, efectos *Scroll Reveal* y transiciones que enriquecen la navegación.
- **Scroll Spy:** identificación de la sección activa para mantener sincronizada la navegación con el contenido visible.

### 3. Personalización de la experiencia

- **Tema claro y oscuro:** selector de apariencia con persistencia mediante `localStorage`.
- **Adaptación de componentes:** ajustes de contraste y colores en tarjetas, formularios, enlaces, estadísticas y elementos secundarios.
- **Preferencias persistentes:** conservación del tema seleccionado entre visitas.

### 4. Integración de conversión (CTA)

- **Formulario de contacto:** recopilación de información para solicitudes de regalos personalizados.
- **Integración con WhatsApp:** generación dinámica de mensajes con los datos ingresados para facilitar el contacto directo con el negocio.
- **Solicitudes personalizadas:** recopilación de información como nombre, correo electrónico, teléfono, tipo de regalo, fecha y mensaje adicional.

> El formulario prepara la solicitud y redirige al usuario a WhatsApp. La coordinación y confirmación de los pedidos se realizan directamente con el negocio mediante este canal.

### 5. Accesibilidad web

- **HTML semántico:** organización estructurada del contenido mediante elementos HTML apropiados.
- **Atributos ARIA:** incorporación de atributos para mejorar la interpretación de los componentes interactivos.
- **Textos alternativos:** descripciones para las imágenes relevantes.
- **Navegación organizada:** estructura de enlaces y controles que facilita la interacción con la interfaz.

### 6. SEO y presencia digital

- **Metadatos enriquecidos:** títulos, descripciones y URL canónica.
- **Open Graph y Twitter Cards:** configuración de vistas previas al compartir el sitio en plataformas sociales.
- **Datos estructurados:** implementación de Schema.org mediante JSON-LD.
- **Indexación:** configuración de `robots.txt` y `sitemap.xml`.
- **Identidad del sitio:** integración de favicons, iconos para dispositivos y `site.webmanifest`.

## 🏗️ Arquitectura del proyecto

El proyecto utiliza una estructura organizada que separa los recursos visuales, estilos y funcionalidades JavaScript, facilitando el mantenimiento y la evolución del código.

```text
detalles-belis-landing/
├── assets/
│   ├── css/
│   │   ├── preloader.css     # Estilos de la pantalla de carga
│   │   └── style.css         # Estilos principales y responsive
│   ├── img/                  # Imágenes, logotipo e iconos
│   └── js/
│       ├── main.js           # Interactividad y funcionalidades principales
│       └── preloader.js      # Control de la pantalla de carga
├── .gitignore                # Archivos excluidos del control de versiones
├── index.html                # Página principal
├── README.md                 # Documentación del proyecto
├── robots.txt                # Directivas para rastreadores
├── sitemap.xml               # Mapa del sitio
└── site.webmanifest          # Configuración de la aplicación web
```

## 🧠 Decisiones de ingeniería

Durante el desarrollo se priorizaron soluciones ligeras, accesibles y fáciles de mantener.

- **Arquitectura estática:** se utiliza HTML, CSS y JavaScript sin incorporar un framework de frontend ni requerir un proceso de compilación para ejecutar el sitio.
- **Interactividad con JavaScript:** las funcionalidades de navegación, formularios, carruseles, modales y animaciones se implementan mediante código JavaScript.
- **Persistencia de preferencias:** `localStorage` permite conservar la selección del tema visual del usuario.
- **Diseño adaptable:** se utilizan breakpoints y ajustes responsive para mantener una experiencia consistente en diferentes tamaños de pantalla.
- **Optimización SEO:** se incorporan metadatos, datos estructurados y archivos de rastreo para mejorar la interpretación del contenido por los buscadores.
- **Separación de recursos:** los estilos, scripts e imágenes se organizan en directorios independientes para facilitar su localización y mantenimiento.

### 🔄 Control de versiones

El proyecto utiliza Git para el seguimiento de cambios y GitHub como repositorio remoto.

Se mantiene una convención de commits basada en prefijos descriptivos:

| Prefijo | Uso |
|---|---|
| `feat:` | Incorporación de nuevas funcionalidades. |
| `fix:` | Corrección de errores. |
| `refactor:` | Mejoras internas sin alterar el comportamiento esperado. |
| `style:` | Cambios de formato o presentación. |
| `docs:` | Actualización de documentación. |
| `chore:` | Tareas de mantenimiento. |

Ejemplo de flujo de trabajo:

```bash
git add .
git commit -m "docs: improve project README"
git push origin main
```

## ⚙️ Instalación y ejecución

### Requisitos previos

- Navegador web actualizado.
- Git para clonar el repositorio.
- Node.js y npm o Python, únicamente si deseas utilizar un servidor local.

### 1. Clonar el repositorio

```bash
git clone https://github.com/Benyarg/detalles-belis-landing.git
```

### 2. Acceder al proyecto

```bash
cd detalles-belis-landing
```

### 3. Ejecutar el proyecto

Al tratarse de un sitio web estático, no necesitas instalar dependencias para visualizarlo.

Puedes abrir directamente el archivo `index.html` en tu navegador.

También puedes iniciar un servidor local para una experiencia de desarrollo más cercana a producción.

**Opción A: utilizando Node.js**

```bash
npx serve .
```

**Opción B: utilizando Python**

```bash
python -m http.server 8000
```

Después, accede a la dirección local indicada por el servidor. En el caso de Python, puedes utilizar:

[http://localhost:8000](http://localhost:8000)
