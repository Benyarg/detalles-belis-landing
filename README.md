## 📖 Descripción

**Detalles Belis** es una landing page profesional desarrollada para un emprendimiento familiar dedicado a la venta de regalos personalizados.

El sitio fue diseñado con un enfoque orientado a la conversión, permitiendo presentar los productos de forma atractiva y facilitando el contacto con clientes potenciales.

---

## ✨ Características principales

* 🎨 **Diseño responsive** — Adaptado para dispositivos móviles, tablets y computadoras.
* 📸 **Catálogo visual** — Presentación de productos mediante imágenes.
* 📩 **Sistema de contacto** — Facilita la comunicación y recepción de pedidos personalizados.
* 🚀 **Optimización SEO** — Uso de metaetiquetas y estructura semántica.
* ⚡ **Buen rendimiento** — Recursos optimizados para una carga rápida.
* ♿ **Buenas prácticas de accesibilidad** — Uso de HTML semántico y estructura organizada.

## 🚀 Instalación local

### Requisitos

No requiere instalación de dependencias para ejecutarse como sitio estático.

### Clonar el repositorio

```bash
git clone https://github.com/Benyarg/detallesbelis.git
cd detallesbelis
```

### Ejecutar localmente

Puedes abrir `index.html` directamente en el navegador.

También puedes utilizar un servidor local:

```bash
npx serve .
```

O utilizando Python:

```bash
python -m http.server 8000
```

Después, abre:

```text
http://localhost:8000
```
